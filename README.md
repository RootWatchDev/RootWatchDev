### 🍿 About RootWatch
RootWatch brings communities together by turning any Root server into a synchronized theater. Friends can stream YouTube videos and direct media with millisecond-accurate timeline synchronization, shared playlists, DJ host controls, and live floating reactions.

- ⚡ **Sub-Second Adaptive Sync** (No drift, no lag)
- 🎥 **YouTube & Direct MP4/HLS Support**
- 📋 **Shared Queue & Instant Quick-Add Presets**
- 👑 **DJ Mode (Host-Only Controls)**
- 🍿 **Real-Time Floating Emoji Reactions**
- 👥 **Live Spectator Presence & Sync Health**

### 🛠️ Ecosystem & Tech
- **Frontend:** React 18, TypeScript, Vite
- **Backend:** Node.js, TypeScript, Root App SDK
- **Networking:** High-performance binary Protobuf over WebSockets
